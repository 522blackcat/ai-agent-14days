# Day 04 Agent 面试题



课程主题：RAG、Embedding、Chunking 与 Qdrant



## Agent 1：不同长度文档如何设计 Chunking？

**参考答案：**结合文档结构、模型 Token 限制、查询粒度和评估结果选择策略。短文档可整体索引；长文档按章节和段落切分；代码按语法结构切分。

**面试官追问：**如何避免表格跨 Chunk 后丢失上下文？

**追问参考答案：**解析时保留表格结构、表头、行列关系和所在章节。可以按完整表格或逻辑行组分块，为每块重复必要表头，并保存原始文档和页码，供回答时回溯。


## Agent 2：向量数据库是否等于 Embedding 模型？

**参考答案：**不是。Embedding 模型将内容转换为向量；向量数据库负责存储、索引、过滤和近似最近邻检索。

**面试官追问：**更换 Embedding 模型后为什么通常需要重新建索引？

**追问参考答案：**不同 Embedding 模型的向量空间和维度可能不同，旧向量与新查询向量通常不能直接比较。应创建新索引、批量重算向量、验证检索质量，再通过双读或别名切换完成迁移。
