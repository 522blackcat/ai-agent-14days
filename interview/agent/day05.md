# Day 05 Agent 面试题



课程主题：BM25、Hybrid Search、RRF 与 Reranker



## Agent 1：为什么 RAG 常使用混合检索？

**参考答案：**词法检索与语义检索覆盖不同的相关性信号。融合可以提高候选召回的稳健性，但会增加索引和查询成本。

**面试官追问：**精确编号查询如何提高词法检索权重？

**追问参考答案：**可以按查询类型识别编号、专有名词和精确短语，提高 BM25 候选配额或融合权重。权重应通过带标注的评估集调整，避免改善精确查询却损害自然语言查询。


## Agent 2：RRF 与 Reranker 是否可以互相替代？

**参考答案：**不能简单替代。RRF 融合不同检索器的排名；Reranker 重新评估查询与候选内容的相关性。两者可组合使用。

**面试官追问：**Reranker 太慢时如何优化延迟？

**追问参考答案：**减少进入 Reranker 的候选数量、批量推理、使用更轻量的模型、缓存稳定查询结果，或根据查询类型决定是否重排。同时观察召回率与延迟，不能只优化速度。
