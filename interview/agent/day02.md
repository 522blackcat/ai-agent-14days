# Day 02 Agent 面试题



课程主题：ReAct、工具系统与执行边界



## Agent 1：ReAct 和普通工具调用有什么区别？

**参考答案：**工具调用是模型请求外部能力的机制；ReAct 是围绕行动和观察组织多步任务的执行模式。ReAct 可以使用 Function Calling 实现。

**面试官追问：**什么时候固定 Workflow 比 ReAct 更合适？

**追问参考答案：**固定 Workflow 适合步骤明确、合规要求严格、结果必须可预测的任务，例如审批、财务写入和固定 ETL。可以只在需要判断的局部节点使用模型。


## Agent 2：如何避免 Agent 无限循环？

**参考答案：**设置最大轮次、总耗时、Token 预算、重复调用检测和明确终止状态。对于写入工具，还应加入审批与幂等保护。

**面试官追问：**模型连续三次调用相同工具且参数相同，如何处理？

**追问参考答案：**识别重复调用后停止当前循环，返回可诊断错误，或在有限次数内调整提示和工具参数。对于写入工具，不能因为重复就再次执行，必须检查幂等键及既有执行结果。
