# Day 08 Agent 面试题



课程主题：FastAPI、SSE 与持久化 Agent 服务



## Agent 1：SSE 与 WebSocket 如何选择？

**参考答案：**主要是服务端向客户端持续推送时，SSE 通常更简单；需要持续双向消息时可考虑 WebSocket。还应评估代理超时、断线恢复和基础设施支持。

**面试官追问：**如何处理客户端断开后仍在执行的 Agent 任务？

**追问参考答案：**先区分连接生命周期与任务生命周期。断开连接后，可以按业务规则取消任务，也可以让持久化任务继续运行并提供任务 ID 供重新查询。无论哪种方式，都需要清理连接资源并防止重复执行。
