## Python 高级面试



## Python 1：Linux 文件描述符耗尽会造成什么问题？

**参考答案：**文件、Socket 和管道等会占用文件描述符。泄漏或并发过高可能导致无法建立新连接或打开文件。

**面试官追问：**如何定位没有正确关闭的 HTTP 连接？

**追问参考答案：**检查客户端是否复用、响应体是否正确关闭、是否在异常路径释放连接。结合进程文件描述符数量、连接状态、客户端连接池指标和请求 Trace 定位泄漏。




## AI Agent 高级面试



## Agent 1：生产级 Agent 部署需要关注什么？

**参考答案：**需要同时考虑 API 服务、模型服务、检索服务、状态存储、任务执行、安全、监控、扩容与数据备份。

**面试官追问：**如果 Qdrant 暂时不可用，服务如何降级？

**追问参考答案：**设置检索超时与熔断，返回明确的暂时不可用状态；对于允许降级的业务，可使用有有效期的缓存结果。不能在没有检索证据时伪装成已验证的知识库回答。
