## Python 高级面试



## Python 1：如何实现有界生产者消费者队列？

**参考答案：**使用有最大容量的队列提供背压，生产者在队列满时等待或拒绝，消费者按并发限制处理任务。

**面试官追问：**如何在服务关闭时安全地处理队列中的任务？

**追问参考答案：**停止接收新任务，等待已接收任务在规定时间内完成，对未完成任务进行持久化或明确失败处理。使用任务确认机制避免任务丢失，并通过幂等键处理重试造成的重复执行。




## AI Agent 高级面试



## Agent 1：如何降低 Agent 成本而不明显损害质量？

**参考答案：**先按请求链路拆分成本，再优化检索候选、上下文、工具输出、模型路由和缓存；通过固定评估集验证质量。

**面试官追问：**为什么不能直接把所有请求切换到小模型？

**追问参考答案：**小模型可能在复杂推理、长上下文、工具选择和结构化输出上表现不同。应按任务类型评估质量与失败成本，通过路由、回退和人工审批平衡成本与可靠性。
