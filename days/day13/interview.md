## Python 高级面试



## Python 1：如何定位高并发 Python 服务的瓶颈？

**参考答案：**先观察请求延迟分布、CPU、内存、事件循环阻塞、连接池、数据库慢查询和下游模型耗时，再针对瓶颈进行压测与优化。

**面试官追问：**CPU 很低但接口很慢，优先检查什么？

**追问参考答案：**优先检查外部模型和数据库耗时、连接池等待、锁竞争、队列排队、网络重试和事件循环阻塞。使用分布式 Trace 分解请求延迟，避免在缺少证据时盲目增加 CPU。




## AI Agent 高级面试



## Agent 1：如何设计高并发企业级 Agent？

**参考答案：**从 SLO 和容量估算出发，拆分 API、任务编排、模型、检索、工具与存储，设计限流、背压、异步任务、缓存、水平扩容和故障隔离。

**面试官追问：**模型服务吞吐达到上限时如何保护整个系统？

**追问参考答案：**使用有界队列、并发信号量、请求限流和超时保护。对非关键任务延迟处理，对可降级任务选择低成本模型，必要时快速拒绝新请求，避免排队耗尽整个系统。
